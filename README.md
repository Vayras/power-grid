# Power Grid

A Bitcoin mining tycoon that teaches how mining really works: hashrate, difficulty retargets,
halvings, power prices, heat, pools and hardware. One fantasy twist sits at the top of the power ladder,
and the game says so.

**Play:** https://vayras.github.io/power-grid/

The game, its Rust/WebAssembly source and the build tools are in [`game/`](game/README.md).
Art sources and credits are in [`assets/`](assets/CREDITS.md) and [`game/CREDITS.md`](game/CREDITS.md).
